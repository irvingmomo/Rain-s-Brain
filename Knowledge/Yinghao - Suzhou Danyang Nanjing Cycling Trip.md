# Yinghao - Suzhou → Danyang → Nanjing Cycling Trip

## Goal

Plan a winter multi-day cultural cycling trip in early December:

**Suzhou → Wuxi → Changzhou → Danyang → Nanjing**

Primary focus: historical remains, authentic sites, landscape context, and literary/history travel rather than commercial scenic spots or reconstructed attractions.

## Core Route

- Suzhou → Wuxi
- Wuxi → Changzhou
- Changzhou → Danyang
- Danyang: South Dynasties imperial tomb stone carvings + other historic sites
- Continue to Nanjing
- Nanjing: literary/history cycling routes
- Before returning: pack and send bicycle back in advance via China Railway Express if available, with SF Express / Deppon as backup
- Take high-speed rail back, collect bicycle on arrival, then ride home

## Danyang Priorities

### Must-see
- South Dynasties imperial tomb stone carvings
- Yanling Jiuli / Jizi Temple area
- Ji Zi-related historic landscape
- Sun Jian tomb / Gaoling if access and location are practical
- Wanshan Pagoda if on route

### Riding Style
- Use the bicycle to connect dispersed rural historical sites
- Prefer original remains and landscape context
- Avoid detours for heavily reconstructed or overpriced attractions

- If a historic site is inside a restricted compound, viewing from a public road is sufficient

## Travel Cycling Strategy

### Daily pace
- Comfortable touring pace rather than performance riding
- Avoid racing on day 1
- Stop every 60–90 minutes for a short break
- Finish riding before dark whenever possible

### Food and water
- Carry two bottles
- Eat small amounts regularly rather than one heavy lunch
- KFC / McDonald's / convenience stores / petrol stations are useful toilet and resupply points

### Toilet / shop stops with panniers
- Lock bicycle to a fixed object
- Leave panniers on the bicycle for short stops
- Carry valuables in a detachable handlebar bag
- For longer meals, park where the bike can be seen if practical
- Remove computer/camera/other quick-release electronics for longer stops

## Packing System

### Rear panniers

### Detachable handlebar bag

## Gear Purchase Strategy

### General rule
Buy almost everything in China unless an item already owned in Australia has a clear fit/comfort advantage.

### Decathlon China — good default buy
- helmet
- padded cycling liner / shorts ×2
- gloves
- photochromic cycling glasses
- rain shell
- quick-dry layers
- bottles
- tubes
- mini pump
- basic repair tools

### Better specialist buys in China
- ROCKBROS waterproof rear panniers
- ROCKBROS handlebar / top-tube bags
- Magicshine front light
- YUEMA U-lock

### Helmet
- Prioritise fit over brand
- Try in store if possible
- MIPS or equivalent rotational-impact system preferred
- Decathlon is a strong default choice because it is easy to try and return
- PMT / GUB are alternatives if fit is better

### Padded cycling shorts / liner
- Essential for consecutive multi-day riding
- Wear directly against skin; no normal underwear underneath
- Buy two pairs and rotate

## Return Logistics

Preferred order:
1. China Railway Express if bicycle handling is available for the relevant station and route
2. SF Express large-item service
3. Deppon large-item service

Before dispatch:
- protect derailleur side carefully
- remove or turn handlebar as required
- remove front wheel if required
- photograph bike before and after packing
- insure / declare value where available

Do not leave packing and dispatch until the final departure hour. Handle it one day earlier if possible.

## Travel Principle

**Original site > surviving remains > historical landscape > reconstructed attraction.**

For restricted or inaccessible sites:

**Public road / exterior view is enough; never force entry.**

The point of the trip is to understand historical geography and landscape, not to collect admission tickets.
