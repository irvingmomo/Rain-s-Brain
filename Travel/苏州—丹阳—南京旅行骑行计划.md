# 苏州—丹阳—南京旅行骑行计划

> [!abstract] 旅行目标
> 12 月上旬从苏州出发，经无锡、常州到丹阳，轻装寻访南朝帝陵石刻，再前往南京游览 2～3 天。旅行结束前提前办理自行车托运，本人乘高铁回苏州；只有在车辆已到达且取件地点合适时，才执行“到站取车骑回家”。

## 一页执行摘要

- 定位：文化旅行优先，不追求速度或单日极限里程。
- 推荐长度：7～9 天；另预留 1 天机动时间。
- 推荐节奏：苏州 → 无锡 → 常州 → 丹阳 → 南京。
- 骑行段：约 200～260 公里，实际以出发点、住宿点和导航绕行为准。
- 行李：后货架双驮包；贵重物品集中在可快速拆卸的随身小包。
- 返程：优先选择能明确受理、打包、保价和提供取件地址的承运方案；中铁快运不可用时改用顺丰或德邦大件。
- 核心原则：不夜骑、不硬扛疼痛、不在恶劣天气中赶进度。

> [!warning] 返程方案的关键限制
> “提前托运”不等于车辆一定与本人同时到达。自行车可能更早或更晚到，取件点也可能不在苏州高铁站。出发前 1～2 周必须向承运方确认：南京受理网点、苏州取件网点、预计时效、保管期限、包装规则、计费、保价和是否送站/送门。未得到明确答复前，不把“下高铁直接取车”写成硬行程。

## 建议行程（舒适版）

| 天数 | 行程 | 参考里程 | 当日重点 |
|---|---|---:|---|
| D1 | 苏州市区 → 无锡 | 50～65 km | 测试衣物、坐垫、驮包与导航 |
| D2 | 无锡 → 常州 | 45～60 km | 稳定巡航，检查车辆 |
| D3 | 常州 → 丹阳 | 45～60 km | 15:00 左右入住，避免天黑赶路 |
| D4 | 丹阳南朝帝陵石刻环线 | 50～80 km | 大件留酒店，轻装寻访 |
| D5 | 丹阳 → 南京 | 约 70～100 km | 视体力、风向和路线拆分或改乘交通工具 |
| D6 | 南京休整与游览 | — | 处理托运，下午开始轻装游览 |
| D7 | 南京游览 | — | 博物馆、城墙或明代遗迹主题 |
| D8 | 南京游览 / 机动日 | — | 补漏、天气缓冲或返程 |
| D9 | 高铁回苏州 | — | 按托运状态决定取车或另行取件 |

> [!tip] 关于 D5
> 丹阳到南京是全程最需要在出发前复核的一段。若训练不足、天气差或不想把文化旅行变成赶路，可拆成两天；也可以结束骑行后通过合规交通方式转场南京。

### 建议先收藏的点位

- [ ] 陵口陵墓石刻
- [ ] 梁文帝萧顺之建陵石刻
- [ ] 梁武帝萧衍修陵石刻
- [ ] 梁简文帝萧纲庄陵石刻
- [ ] 齐宣帝萧承之永安陵石刻
- [ ] 齐景帝萧道生修安陵石刻
- [ ] 齐武帝萧赜景安陵石刻
- [ ] 齐明帝萧鸾兴安陵石刻
- [ ] 金王陈南齐失名墓石刻
- [ ] 烂石弄南齐失名墓石刻
- [ ] 水经山南朝失名墓石刻

### 寻访方法

- 出发前逐点在高德地图复核名称、道路、入口和最新评论；旧地名或墓主认定可能不同。
- 第一次不强求全收集，优先保证陵口、建陵、修陵以及相邻成组点位。
- 大件行李留在丹阳酒店，仅带水、补给、维修包、充电宝和随身贵重物品。
- 不翻围栏、不攀爬石兽、不踩农田；遇到村民礼貌说明来意。
- 乡村点位默认没有厕所、商店或工作人员，每 2～3 个点安排一次补给。

## 南京段规划

### 主题备选

- 六朝与城市：南京博物院、六朝博物馆、台城与玄武湖一带。
- 明代遗迹：明孝陵、明城墙、老门东。
- 轻松散步：玄武湖、颐和路、秦淮河沿线。

### 自行车如何处理

1. 抵达南京当晚，车辆进入酒店室内安全区域或客房；订房前确认可否存车。
2. 次日上午到提前联系好的自行车店检查、拆装并打包。
3. 完成托运并保存运单、车辆照片和包装照片。
4. 后续南京行程改为步行与公共交通，减少防盗压力。

## 返程与托运决策

### 推荐顺序

1. 中铁快运：仅在南京受理点、苏州取件点和时效均已确认时采用。
2. 顺丰大件：询问能否收自行车、包装要求、保价和送达方式。
3. 德邦大件：作为第二物流备选，同样确认包装和理赔规则。

### 办理前必须问清

- [ ] 南京哪个网点实际受理自行车？营业时间是什么？
- [ ] 是否必须纸箱或木架？网点是否提供包装？
- [ ] 是否需要拆前轮、脚踏或转动车把？
- [ ] 苏州在哪里取车：车站、营业部还是送货上门？
- [ ] 预计几天到达？延误时如何处理？
- [ ] 到达后免费保管几天？
- [ ] 计费重量、体积重量和总价是多少？
- [ ] 保价上限、免赔条款和理赔凭证是什么？
- [ ] 驮包能否与车同箱，还是需要单独寄？
- [ ] 电池、气瓶、润滑油等是否有限制？

### 打包重点

- 拍摄整车外观、车架号和已有划痕。
- 拆下码表、灯具、相机、水壶和可快速拆卸配件，随身携带。
- 保护后拨、刹车碟片、前叉端和车架易摩擦处。
- 拆前轮后使用前叉运输垫块；碟刹使用来令片垫块。
- 将车把固定，避免线管被拉扯或折死。
- 空隙填充并防止零件在箱内移动；封箱前、封箱后各拍照。
- 运单备注自行车并购买合理保价，保留收据。

## 车辆、行李与防盗

### 推荐装载

- 左驮包：衣物、洗漱、拖鞋、防雨层。
- 右驮包：维修、电子配件、锁、药品；左右重量尽量接近。
- 随身小包：手机、钱包、身份证、现金、相机、充电宝、钥匙。
- 车上易拆件：停车超过约 20 分钟时取下码表、前灯、相机和可拆尾灯。

### 临时停车

- 厕所/便利店：车架锁到固定物，贵重小包随身，驮包通常留车上。
- 正餐：尽量坐在能看见车的位置；长时间离开时增加钢缆固定车轮与驮包。
- 酒店：双驮包全部取下，车辆停室内；不把整车长期放在街边。
- 头盔：带进室内，或把带子穿入锁内防顺手拿走。

> [!note]
> 追踪器只能辅助找回，不能代替可靠锁具、固定物和视线管理。贵重物品始终不放在后驮包。

## 补给、节奏与恢复

- 移动均速以 16～20 km/h 为参考，不为维持数字硬踩。
- 每 15～20 分钟喝几口；每小时约 400～600 ml，按气温和出汗调整。
- 每小时补充约 30～50 g 碳水：香蕉、饭团、面包、能量棒等。
- 每骑 60～90 分钟停 5～10 分钟；每 2～3 小时安排较长补给。
- 轻齿比、较顺畅踏频；能说完整句子，大腿不持续酸胀。
- 每隔几分钟换手位、放松肩膀；定期站立踩踏 10～20 秒。
- 午饭七成饱，避免大份油腻餐，饭后休息约 20 分钟。

### 每晚 15 分钟流程

- [ ] 驮包整包进房，挂好第二天衣物
- [ ] 洗澡、换干衣、检查皮肤摩擦处
- [ ] 正常吃晚饭并补水
- [ ] 检查胎压、外胎、刹车、链条和货架螺丝
- [ ] 擦干链条；需要时少量润滑
- [ ] 所有电子设备充电
- [ ] 查看次日天气、风向、路线和退出点
- [ ] 尽量 22:00 前睡觉

## 停止骑行标准

遇到任一项，应缩短行程、改乘交通工具或就近住宿：

- [ ] 中到大雨、路面结冰或能见度明显下降
- [ ] 手指冷到无法可靠操控刹车
- [ ] 膝盖尖锐痛、单侧异常痛、持续麻木或皮肤破损
- [ ] 连续两次机械故障
- [ ] 精神难以集中或明显低血糖
- [ ] 预计天黑时仍有 30 km 以上
- [ ] 强逆风导致无法按安全时间到达

## 出发前训练与准备

### 8～10 周训练

- [ ] 第 1～2 周：20～30 km 一次；40 km 一次；练会拆轮换胎
- [ ] 第 3～4 周：30 km 一次；50～60 km 一次；半负重试骑
- [ ] 第 5～6 周：40 km 一次；70～80 km 一次；完整模拟补给
- [ ] 第 7～8 周：连续两天骑 60 km + 40～50 km
- [ ] 出发前一周：只做 20～30 km 轻松骑，完成车辆保养

### 出发前两周

- [ ] 检查刹车、外胎、链条、变速、轮组与货架螺丝
- [ ] 满载试骑至少 30 km
- [ ] 预订可室内存车的酒店
- [ ] 联系南京自行车店和至少两家承运方
- [ ] 确认南京打包、寄件和苏州取件方案
- [ ] 确认高铁票的退改规则，给天气留机动日

### 出发前一晚

- [ ] 天气与风向已确认
- [ ] 路线和离线地图已准备
- [ ] 每晚住宿与退出点已截图
- [ ] 灯具、手机和充电宝已充满
- [ ] 胎压、刹车、货架和驮包固定正常
- [ ] 备用内胎、打气筒、工具齐全
- [ ] 身份证、现金和首日补给已装好
- [ ] 家人知道当天目的地与预计到达时间

```text
假设你有10万公里旅行骑行经验，请给出至少50条真正能减少弯路的经验，不要用空泛口号或堆砌常识。重点回答：如何每天骑完不过度疲劳、减少屁股疼、降低爆胎概率、把每日收拾控制在15分钟、南京期间处理自行车、避免托运踩坑，以及如果这是一次从容的退休旅行，你会如何优化苏州→丹阳→南京全程。
```

## 待确认事项

- [ ] 最终出发日期与可用总天数
- [ ] 苏州具体起点及返程车站
- [ ] 当前自行车型、轮胎宽度、货架和驮包
- [ ] 是否完成连续两天负重训练
- [ ] 丹阳帝陵点位的最新可达性
- [ ] 丹阳到南京采用一天骑行、两天拆分或交通转场
- [ ] 南京酒店的室内存车政策
- [ ] 南京自行车店的打包预约
- [ ] 中铁快运是否实际受理及苏州取件点
- [ ] 顺丰、德邦备选报价与时效
- [ ] 高铁票、机动日和恶劣天气退出方案

## 最终建议

这趟旅行最稳妥的版本是：前三天从苏州经无锡、常州到丹阳；第四天把大件留在酒店，轻装看南朝帝陵；第五天按训练和天气决定骑往南京、拆分行程或交通转场；到南京后尽早完成自行车打包托运，再用 2～3 天轻装游览。返程时以物流状态决定取车方式，不让车辆到达时间绑架高铁行程。
